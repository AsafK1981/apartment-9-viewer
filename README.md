# Apartment 9 planning dossier and interactive viewer

Approved r7 apartment layout in a self-contained browser viewer.

The current r9 display replaces the sink-wall shelves with upper cabinets around the retained window, removes the pantry and adds two tall open rounded corner display units. The entrance electrical panel, all original windows and balcony sliding exit remain visible. The saved room layout is preserved. The proposed bathroom extension beside the MMD is not implemented because the approximate door-sweep study shows a collision; verified door details are required.

Open the root page to explore the model. Use the room selector and drag to look around. In the overview and top views, pinch with two fingers or use the plus and minus buttons to zoom. The model and dimensions are illustrative, based on the approved design study.

Open project/ for the Hebrew planning dossier: the current plan, readable decisions, architect questions, original drawing and clearly labeled planning history. Fridge selection, final panel details and feasibility and cost of the relocated guest and master toilets remain open architect questions.

This repository contains the standalone public viewer and a curated export of planning documents and design images. Operational files, internal instructions, test reports and unrelated workspace materials are kept outside this repository. GitHub Pages serves these static files without a paid runtime service.
